# Spark Big Data Labs

PySpark learning labs for big data processing, clustering, classification, regression, and recommender systems.

## Purpose

This repository collects PySpark practice examples. It is a lab/reference workspace rather than a production Spark application.

## Contents

- Classification examples.
- Regression examples.
- K-means and clustering examples.
- Recommender examples.
- Supporting resources for local Spark experiments.

## How To Use

Open a specific lab folder and run the relevant Python or Spark script with the required local Spark environment.

## Status

Active learning repo. The next upgrade is to add per-lab prerequisites, expected outputs, and generated-artifact cleanup rules.

## Validation

For each lab, document the input data, expected output, and generated artifacts. Keep local Spark output out of source control.

## Engineering Notes

Spark labs should separate source code from runtime output and make environment assumptions explicit.
